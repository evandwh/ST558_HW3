Question 4

What are the two main differences between a tibble and a data.frame?

Tibbles print cleaner and usual return a tibble when you subset them. This makes them easier to chain.

Data frames try to print everything by default, but usually try to print out a vector, making them not print results as cleanly. Also, not easily chain-able.

Question 5

Rewrite the following nested function call using baseR’s chaining operator:

library(tidyverse)
arrange(filter(select(as_tibble(iris), starts_with("Petal"), Species), Petal.Length < 1.55), Species)

Answer:

as_tibble(iris) |>
  select(starts_with("Petal"), Species) |>
  filter(Petal.Length < 1.55) |>
  arrange(Species)

Question 6

What is meant by long format data and wide format data? Which do we generally prefer for statistical analysis?

Long format - Each row is a single observation Wide format - Each row is a subject, different columns are different observations

For statistical analysis, we perfer long form as it is much easier to work with for modeling and is more flexible. It is also easier to group and summarize.

Manager_WinPer_Data <- tbl(con, "Managers") |>
  select(playerID, G, W, L) |>
  group_by(playerID) |>
  summarize(G_managed = sum(G, na.rm = TRUE),
    Total_W = sum(W, na.rm = TRUE),
    Total_L = sum(L, na.rm = TRUE)) |>
  collect() |>
  mutate("Win_Percent" = Total_W/G_managed) |>
  arrange(desc(Win_Percent))
